# PCDSNet supplementary materials

This repository provides supplementary experimental results and qualitative examples for PCDSNet. The tables report accuracy as percentages; SD denotes sample standard deviation in percentage points. References in these materials follow the numbering of the main manuscript.

- [Experimental results](experimental_results.md): implementation details, repeated runs, ablations, sensitivity analyses, and transfer results (Tables A.1–A.11).
- [Qualitative examples](qualitative_results.md): failure cases and illustrative comparisons (Figures A.1–A.2).
- [Complete supplementary appendix (PDF)](supplementary_material.pdf).

The qualitative examples use a separate seed-17 run. The LSKNet comparison uses a different pipeline and a checkpoint trained on DOTA trainval, which may overlap the displayed validation tiles; it is illustrative.
